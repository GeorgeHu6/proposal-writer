# 章节对应与占位示例

此文件说明写作方法，正式交付按完整目录形成实质正文，不直接交付示例。

以“面向城市内涝的多源感知与协同调度关键技术研究”为例，可建立以下内容联系：

第一部分围绕多源感知、机理约束预测与排水调度比较代表性方法，指出稀疏观测、预测不确定性传递与设施约束协同方面的研究问题。每项精确技术比较须有核验过的来源；不足处使用【请补充支持本项技术比较的代表性原始论文、年份及实验结果】。

第二部分提出状态估计、风险预测和协同调度等具体目标；主要研究内容按同一组问题展开；研究方法解释数据融合、机理建模、约束优化和验证的实现过程；课题分解说明状态估计输出如何进入预测、预测如何驱动调度、验证结果如何修正模型。创新点从观测融合机制、不确定性传递或约束协同方法中凝练，不只说建设平台。

指标表中，状态估计误差、预警提前量和调度可行性分别对应相关课题，缺少数值时写【请填写状态估计误差目标值及同条件测试基线】，相邻列正常写明测试数据、比较方法和计算口径，不用“建议值待确认”代替实际填写提示。

第四部分按前述依赖安排基础数据整理、关键方法研究、模块联调和综合验证。时间位置写【请填写本阶段起止时间并与总周期一致】，研究内容和成果交接关系应写清，不套用抽象月份标签。

第五部分针对数据共享、模块接口、试验调度和结果质量设置具体实施机制。数据及场景条件写【请填写数据来源、使用授权、示范区域及排水设施可控范围】。权益条款写【请填写合作各方已确定的成果权属、署名规则、许可方式和收益分配原则】。不生成第三部分，也不虚构已签署的合作。

课题标题排版举例：

- Heading 1：第二部分 研究目标及内容
- Heading 2：三、课题分解方案
- Heading 3：（二）各课题内容
- Heading 4：1. 课题1 多源感知与状态估计研究
- Heading 5：1.1 研究目标
- Heading 5：1.2 主要研究内容
- Heading 6：（1）缺测条件下的多源观测融合

以上层级必须在Word中使用真实标题样式，不能全部加粗后放在同一层。
