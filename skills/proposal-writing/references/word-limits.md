# 各章节默认字数

## 依据与计数口径

本规则以用户提供的人工智能重大专项申报书和绿色智慧校园申报书为篇幅样本，保留第一、第二、第四、第五部分。统计及默认分配不含第三部分、预算和人员材料。机器执行的预算见[word-limits.json](word-limits.json)。

默认采用“中文有效叙述字数”：中文汉字逐字计数；不计标题、标点、空白、英文、数字、表格、图题、参考文献以及【请填写……】等中文方括号填写提示。正常正文中的汉字每次出现均计数，但不能用重复段落补足篇幅。表格文字量和填写提示数量另外统计，不抵扣叙述正文要求。这是统一的写作统计口径，不等同于Word的字数或字符数。

源文件先按PDF页序与章节边界提取文本，排除可识别的页脚、水印、图表题、表格及填报说明页，并从各课题统计中排除参加单位任务分工段。图中与表格内文字不作OCR，未逐项识别的细标题可能仍有少量计入，因此源样本数字是近似的正文篇幅参考。下表样本值取百字近似数；默认值是根据两份样本整理后的写作目标，不是声称样本有同一固定字数。

## 每个课题内部

两份样本合计9个课题，按相同栏目分别统计后，形成以下目标。范围兼顾两份样本的不同写法，而非要求所有课题同等复杂。

| 课题下栏目 | 样本观察范围约字数 | 默认目标 | 允许范围 |
|---|---:|---:|---:|
| 研究目标 | 120—430 | 250 | 100—450 |
| 主要研究内容 | 870—1,680 | 1,250 | 850—1,750 |
| 拟解决的科学或技术问题 | 240—530 | 400 | 240—550 |
| 考核指标及测评方法 | 210—300 | 300 | 200—400 |
| 每课题合计 | 约1,500—2,600 | 2,200 | 1,500—2,700 |

各课题作为四级标题，以上四项分别作为五级小节；专题细化到六级时，其正文计入所属五级小节，不重复累计。单位职责等依赖真实情况的栏目可使用具体填写提示，不单独分配用于凑字的配额。

## 父章节与全篇汇总

父项包含下级内容，汇总时只计算一次，不再为父项另写一份同等长度的重复概述。

| 汇总项 | 默认目标 |
|---|---:|
| 第二部分 一、项目目标及考核指标 | 3,700 |
| 第二部分 二、项目研究内容、研究方法及技术路线 | 5,900 |
| 第二部分 三、课题分解方案 | 1,300＋2,200×N |
| 第二部分合计 | 13,500＋2,200×N |
| 第五部分合计 | 3,100 |
| 全篇合计 | 18,700＋2,450×N |
| 4个课题的全篇 | 28,500 |
| 5个课题的全篇 | 30,950 |

各部分统领段计入所在部分，小节之上的统领段不用于替代小节字数。不能为减少篇幅而合并应分别论证的课题，也不为增加篇幅而拆出没有独立研究意义的课题。

## 其他内部小节的建议分配

第一部分可参考国外现状650、国内现状650、趋势与问题300字；按技术方向组织时保持总量和比较深度即可。目标与指标小节可参考目标500、指标及测评说明1,200字。主要研究内容可参考科学问题600、技术问题800、具体研究内容1,200字。研究方法可参考方法与总体路线1,800、可行性及先进性1,500字。创新点通常每项约350—500字，最终以项目实际创新数量和该章总量为准。

以上分配用于组织内容，不额外强制生成原目录以外的标题，也不作为独立的自动上下限；自动检查针对上面的规定栏目及课题四项小节。

## 用户与指南要求优先

用户或本次指南有明确分节字数时，以其为准。只给总字数时，按默认比例缩放；指定某章时调整该章及对应子项，不擅自改变其他明确要求。在工作JSON中可用length_requirements记录，栏目键使用完整标题路径，避免同名栏目混淆：

```json
{
  "length_requirements": {
    "total": {"target": 24000, "min": 22000, "max": 26000},
    "sections": {
      "第一部分 国内外现状及趋势分析": {"target": 1500, "min": 1300, "max": 1700}
    }
  }
}
```

target、min、max为正整数；缺少上下限时，覆盖要求默认采用目标的80%—120%。父章要求按其子项既有比例分配，更具体的小节要求优先。用户要求相互冲突时说明具体冲突，不能为了通过检查擅自改动。若指南使用Word字符数、包括图表等不同口径，应按其另行核对，并把叙述预算相应调整，不能将这里的汉字数声称为该指南的精确统计。

指南明确“不超过某字数”时，max必须使用该上限，target安排在上限以内，不按默认浮动比例放宽上限；明确“至少某字数”时，相应保留其下限。默认浮动范围不能取代本次指南的硬性限制。

## 生成前检查

先完成各栏目到接近目标篇幅，再运行scripts/word_limits.py保存工作报告。报告列出实际正文、目标、上下限、表格文字量和填写提示数量，并汇总父章及全篇。默认重大专项目录下，Word生成器遇到字数不合格会停止并报告具体栏目，先修订再生成。

图题或文献条目若以普通paragraph块存在，设置role为caption或reference；正常研究论述不得标记为这些角色。内容不足时补充科学机理、方法步骤、变量与约束、对照实验、结果评价或课题协作关系；避免重复、空话、堆砌算法名称或延长填写提示。字数合格不能替代内容质量审查。
