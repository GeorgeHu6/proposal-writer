# 项目申报书写作助手

1.4.0版按照用户指定的重大专项申报书目录，生成一份可编辑Word正文。

默认只保留第一部分“国内外现状及趋势分析”、第二部分“研究目标及内容”、第四部分“进度安排”、第五部分“项目组织实施、保障措施及风险分析”，第三部分整体省略并保留后续编号。第二、第五部分的章节目次严格按指定目录组织，各部分内部再按研究逻辑分层。

Word使用真实标题样式区分部分、章、节、课题和内部小节，支持至六层。正文与表格可编辑，不强制封面、目录、页码或精细格式。

写作时要求现状不足、研究目标、研究内容、研究方法、课题分解、创新、指标、进度与保障内容相互对应。正式正文使用具体名称，不采用“冻结指标”“P1/P2”等写作管理用语，不加入反复的免责声明。依赖真实情况的信息用【请填写……】或【请补充……】提示，明确用户应提供的内容；不虚构单位、资源、协议、日期和指标数值。

选择插件后发送项目名称即可起草；也可补充指南、已有研究方案、指标和项目周期。实际资料缺口在相应栏目中占位，可设计的技术内容会完整撰写，不只返回目录模板。默认不含预算、人员组成、名单、履历或合作单位研究基础专章。

插件内置目录模板、正式语体规则、章节对应要求、Word生成器及明确规则检查。生成前自动检查目录、标题层级、部分典型用语和填写提示；研究论证是否充分仍按写作审查规则检查。模板和示例不作为真实项目成绩或外部证据。

文档生成需要环境已有文档工具，或Python与python-docx。内置程序不联网或上传，插件没有独立托管文档服务。

## 默认篇幅

依据两份原申报书的叙述正文统计，按章节和课题分别设置字数目标及允许范围，替代原8,000—12,000字总篇幅。默认4个课题约28,500个有效正文汉字，5个课题约30,950字；项目实际课题数决定总量。每课题目标2,200字，并分别检查研究目标、主要研究内容、关键问题和指标测评四个小节。

正文按中文汉字逐字计数，不含标题、表格、图题、参考文献、英文数字、标点空白及【填写提示】；表格和填写提示单独报告。父章含下级内容但汇总不重复计数。用户或本次指南的明确篇幅优先，可覆盖默认预算。

生成器在导出Word前检查篇幅，报告过短或过长的栏目，先修订再生成。详细标准见技能的references/word-limits.md及word-limits.json。源样本采用可提取叙述文字的近似统计，图像化表格未作OCR，不作为零字范本。

## 正面直接的成稿与终稿回读

1.4.0版强化直接项目叙述，以研究对象、动作、方法、成果用途、适用范围和实施程序组织正文。实际信息、待填内容、填写建议、核实要求和填写方法完整放入【】。限制性套话、否定式管理口吻、自述提醒和免责句式按具体含义改写为项目的实际安排，科学条件与真实约定保持准确。

formal_style.py与结构检查共用语体规则，覆盖“仅提供参考”“不能直接替代”“不能据此推定”“不得……”“不将……”等句式及部分变体，并检查括号外填写建议。Word生成后回读正文、表格、页眉页脚和脚注尾注，命中位置先修订，再重新检查。内置生成器在检查通过后保存最终文件；使用其他文档工具时同样执行实际DOCX终稿核查。
